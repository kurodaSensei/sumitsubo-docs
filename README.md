# sumitsubo-docs

The documentation site for [Sumitsubo](https://github.com/kurodaSensei/sumitsubo) — a
plugin framework for Claude Code. Built with the framework itself, which is the
point: if it did not hold up, this site would show it.

**<https://sumitsubo-docs.vercel.app>**

Nuxt 4, fully prerendered, bilingual. Spanish is the default and sits at the
root; English lives under `/en/`.

## Run it

Node 22.19+ or 24.11+ (see `engines`).

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run check      # 10 assertions — routes, tokens, translation fidelity
npm run generate   # the static build, 94 routes
npm run sync       # re-vendor the reference content from the framework
```

## The reference pages are not written here

All 44 of them are generated by `npm run sync`, which clones the framework,
renders its markdown to HTML in Node, and writes `content/index.json` plus one
JSON file per page. Pin a release with `--ref`:

```bash
npm run sync -- --ref v0.6.1
```

The sync **refuses to run** when the framework has gained or lost a skill or a
command, because the site cannot publish a page that has no Spanish
translation. Bump `EXPECTED` in `scripts/sync-framework.mjs` and write the
translation in the same commit — that refusal is the feature.

Translations live in `content/<locale>/`, are written by hand, and record a
hash of the English body they were made from, so the sync reports when upstream
has moved underneath one.

`.github/workflows/sync.yml` does all of this on a release and opens a PR. It
never merges.

## What the checks protect

`npm run check` is plain assertions, no test framework. The ones worth knowing:

- Every URL the pages link to is a URL the build prerenders. They come from
  different code, and when they disagree the build still passes green while
  every page 404s.
- Every `<pre>` and every `<code>` in a translation is **byte-identical** to the
  English. It has caught nine real slips — a translated identifier, a reordered
  pair, a split code span.
- Heading anchors match across locales, so a deep link shared between them lands.
- No Spanish page uses voseo.

## Layout

```
app/              pages, layout, composables, tokens
content/          index.json + the hand-written translations
server/assets/    the rendered pages the content route serves
scripts/          sync and the checks
design/           tokens.mjs — the generator DESIGN.md is the source for
DESIGN.md         type, colour, motion, the grid, the chamfer
PRODUCT.md        what the site is for and what it refuses to be
```
